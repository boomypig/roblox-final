# Vault index

Design research for choosing and designing a Roblox game. Load this file, pick the names that
match your task, and load only those. If a name is not enough to decide, the full read-when
line of every file is in [CATALOG.md](CATALOG.md). Writing rules: [CONTRIBUTING.md](CONTRIBUTING.md).

## Patterns: `vault/patterns/<name>.md`

Read one when the game adds that mechanic.

- `player-data`: saving anything
- `round-system`: lobby, intermission, match state
- `checkpoints-and-respawn`: checkpoints, respawn, stage progress
- `rebirth-prestige`: resets and multipliers
- `rarity-tiers-and-eggs`: eggs, gacha rolls, odds
- `pets-companions`: pets that follow, equip or boost
- `trading`: player-to-player trading
- `base-defense-and-stealing`: raidable bases, locks, stealing
- `idle-offline-income`: passive or offline income
- `conveyor-dropper-economy`: droppers, conveyors, collectors
- `upgrade-trees`: upgrade paths, cost curves
- `daily-rewards-and-streaks`: login rewards, streaks
- `quests`: quests, missions, achievements
- `codes`: redeemable codes
- `leaderboards`: in-game or global boards
- `boss-fights-and-raids`: bosses, raids, co-op PvE
- `ability-kits`: ability kits, cooldowns, combat
- `shops`: soft-currency or Robux shop
- `inventory`: inventory, equipment, storage
- `server-events-admin-abuse`: server-wide events, weather
- `private-servers`: private (VIP) servers

## Fundamentals: `vault/fundamentals/<name>.md`

- `discovery-algorithm`: what to optimize for recommendations; launch; audience gating
- `retention`: session goals, return reasons, D1/D7/D28
- `first-time-experience`: spawn, tutorial, first 10 minutes
- `metadata-thumbnails-icons`: title, description, icon, thumbnail; before publishing
- `monetization`: any pass, product, subscription or purchase code
- `social-and-virality`: co-play, invites, clip-worthy moments
- `live-ops-and-updates`: updates, events, limited-time content
- `trend-lifecycle`: joining a trend or clone wave; adding a spin
- `audience`: target players, devices, languages, pricing
- `analytics`: analytics events; reading Creator Analytics

## Trends (generated by tools/trends, never hand-edit)

The trends report is your own data, so it is not part of the tracked tree. `tools/trends` writes
it to `private/trends/latest.md`, with dated copies in `private/trends/history/`. Read it when
choosing a game idea, judging saturation, or citing what is popular now. If it is missing, say
so, then either run `collect` and `report` (tools/trends/README.md) or continue without market
numbers and say that in the output.

## Case studies (private notes)

Case studies of named games are personal research notes. They are kept in
`private/case-studies/<slug>.md`, listed in `private/case-studies/INDEX.md`, and follow the same
writing rules. Vault files point at one as `(case study: <slug>)`.

If `private/case-studies/` is missing, skip the case study and say so: the genre file's
"Top examples" section still carries the one-line summary of each game.
